Sumyst is an independent browser extension. This page describes the extension in this repository and its project website.

Summaries and questions

When you ask for a summary or an answer, Sumyst sends the selected or extracted source material and your instructions through the ChatGPT interface using your signed-in browser session. Long sources can require multiple requests. ChatGPT handles those requests under your account and OpenAI’s terms and privacy policy. Sumyst does not require an OpenAI API key.

Data stored in your browser

Settings, summary caches, and batch sessions are stored in extension browser storage. Batch data may include source URLs, titles, summaries and page images. Exported sessions contain this data in the file you save. Clear batch results through the workspace, and remove the extension to remove its extension storage. Files you have exported remain wherever you saved them.

Usage statistics

Usage statistics are enabled by default unless you have saved an opt-out. You can turn them off during onboarding or under Settings → Usage analytics. Turning them off stops event sends and clears the local analytics identifiers.

Allowlisted events contain feature names, counts, an independent random installation identifier, a session identifier, and the extension version. They exclude source text, page URLs, summaries, questions, ChatGPT credentials, API keys and raw error messages. The relay forwards allowed events to Google Analytics property G-WV65497MC0 when configured.

The HTTPS relay is hosted on Cloudflare. Requests expose ordinary connection metadata, such as an IP address, to hosting infrastructure; the relay uses IP-derived information for request rate limiting. Do not treat usage analytics as anonymous browsing. The website itself does not load Google Analytics or advertising scripts.

Page images and permissions

Site preview images may be fetched from the source site. Chrome screenshot capture uses optional debugger permission, requested when you choose that feature. Source tabs close only if you enable that setting; it is off by default.

The project website

This static site is hosted by GitHub Pages. GitHub receives normal web request information when you visit it. No newsletter, account signup, tracking pixel, or advertising network is embedded here.

Questions and source

Review the public source or open an issue for project questions. Do not include private source material, tokens, or account credentials in public issues.
